# FashionProject — Full-Stack E-Commerce Web Application

A full-stack, dynamic e-commerce platform developed using **Java Servlets, JSP, JDBC, and MySQL**. The application features robust customer shopping capabilities alongside a comprehensive administrative dashboard for inventory and order management.

---

## ✨ Features

### 🛍️ User Capabilities
- **User Authentication:** Secure registration, login, and session management.
- **Product Catalog:** Interactive browsing of products categorized by clothing and accessories.
- **Shopping Cart & Wishlist:** Dynamic item addition/removal, quantity adjustments, and live price recalculation.
- **Order Placement:** Integrated checkout workflow with order records saved securely to the database.

### 🛡️ Admin Dashboard
- **Product Management:** Full CRUD operations (Add, Edit, View, Delete) for product listings.
- **Order Monitoring:** Track customer orders, transaction records, and buyer details.
